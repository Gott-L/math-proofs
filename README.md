# Gott-L mathematical proofs

Mathematical proof development, Lean formalizations and reproducibility records led by Gott-L.

## Project roles

Gott-L initiated the project, proposed its objectives and research direction, and leads planning and submission. Codex performs substantive mathematical research, proof construction, implementation, documentation and internal checks. Each contribution must retain its own prior-work attribution and applicable licenses. Repository ownership does not establish authorship of inherited work.

## Submission status

A research result is eligible for a complete-problem submission only after its exact statement has been checked against every requirement of the original problem. A complete formalization of a special case or auxiliary theorem is not a complete solution to a broader problem.

The nine historical packets referenced by [awards PR #629](https://github.com/TheJustinSunPrize/awards/pull/629) are scoped research results. Their original [fixed index](https://github.com/Gott-L/awards/blob/44a7aae060332841d74ef99c335482890b7f4499/evidence/gott-l-formalization-index.md) and public history remain available. This repository does not claim that those packets solve all associated catalogue questions, that they have passed the current mandatory pre-submission workflow, or that an award has been accepted.

Only cleared source and evidence may be added here. Each future proof submission must identify an immutable commit, exact theorem, original-problem correspondence, pinned dependencies, reproduction procedure, attribution, and a verification report tied to that commit. Reports added later must distinguish their evidence commit from the proof commit they describe.
